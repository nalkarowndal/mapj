# UI/UX 개선 및 리디자인 계획서 (UI_UX_IMPROVEMENT)

## 1. 기존 UI/UX 한계 및 문제점 분석
1. **단조롭고 답답한 5:5 2열 분할 레이아웃**:
   - 데스크톱 화면에서 사이드바가 부재하여 대화 이력, 즐겨찾기, 빠른 구(District) 전환 관리가 불가.
   - 지도가 열리면 채팅 영역의 너비가 50%로 고정되어 대화 가독성이 급격히 저하됨.
2. **환각 유발 및 가짜 지도**:
   - 지도가 실제 지도 SDK가 아닌 정적 배경 점박이 이미지로 되어 있어 확대/축소/이동/실제 마커 조작이 불가능.
   - 장소 데이터가 가상 생성되어 사용자의 신뢰를 손상시킴.
3. **모바일 사용성 훼손**:
   - 모바일 환경에서 사용자가 질문 후 답변을 읽기도 전에 `useEffect`에 의해 강제로 '지도 보기' 탭으로 전환되어 대화 맥락이 끊김.
   - 1줄 단일 `input` 태그로 긴 프롬프트 작성이 어렵고 한글 IME 엔터 입력 시 중복 전송 문제 상존.
4. **시작 화면의 빈약성**:
   - 첫 방문 시 "안녕하세요" 단일 말풍선만 있어 무엇을 어떻게 물어봐야 할지 가이드 부재.

## 2. 신규 UI/UX 개선 방안

### 2.1 3-Column 현대적 대시보드 레이아웃
1. **Left Column (탐색 & 기록 사이드바)**:
   - AI 로컬 어시스턴트 브랜드 로고 & 버전
   - `+ 새 대화 시작` 버튼
   - 5대 자치구(노원구, 도봉구, 강북구, 중랑구, 성북구) 퀵 스위처
   - 최근 대화 세션 목록 (로컬 저장소 동기화)
   - 사이드바 접기/펼치기 토글 (데스크톱 공간 자유 활용)
2. **Center Column (AI 채팅 & 추천 내러티브)**:
   - 상단 헤더: 선택된 지역 배지, 시스템 연결 상태(실시간 API / 검증 로컬 모드)
   - 시작 화면: 실전 질문 예시 칩(맛집, 가족 외식, 스터디 카페, 학원 등) 원클릭 전송
   - 메시지 카드: 복사 버튼, 마크다운 코드/표/리스트 최적화, 출처 배지
   - 입력 바: 자동 높이 조절 텍스트에어리어, 한글 조합 대응, Shift+Enter 줄바꿈, 최하단 스크롤 인디케이터
3. **Right Column (인터랙티브 지도 & 장소 탐색기)**:
   - 실시간 카카오맵 연동 (SDK 미설정 시 고해상도 벡터 인터랙티브 폴백 맵 완벽 지원)
   - 지역 변경 시 지도 중심 자동 부드러운 패닝(PanTo)
   - 카테고리 퀵 필터 (전체, 맛집, 카페, 학원, 문화시설)
   - 장소 카드 & 지도 마커 양방향 100% 실시간 하이라이트 동기화
   - 장소 상세 정보 모달 및 카카오맵 길찾기 외부 링크 연동

### 2.2 모바일 전용 반응형 전략
- 하단 네비게이션 바(Bottom Nav Bar): `💬 대화`, `📍 추천장소`, `🗺️ 지도` 3단 탭
- 사용자 동의 없는 강제 탭 전환 완전 배제 (현재 보고 있는 뷰 존중)
- 지도 탭 선택 시 하단에 장소 요약 바텀시트(Bottom Sheet) 오버레이 제공
- 터치 영역 최소 44px 이상 확보 및 모바일 키보드 열림 시 레이아웃 깨짐 방지
