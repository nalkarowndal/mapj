## 3. 발견된 결함 및 수정 내역

1. **결함 1**: `mdb-react-ui-kit`의 React 19 peer dependency 충돌로 `npm install` 실패.
   - **조치**: 컴포넌트에서 미사용 중인 `mdb-react-ui-kit`을 패키지 목록에서 제거하고 순수 Tailwind CSS 4 기반의 재사용 가능한 `Button`, `Badge`, `Card`, `Modal` 컴포넌트로 전면 재구축함.
2. **결함 2**: Groq API 호출 시 잘못된 모델명(`openai/gpt-oss-120b`) 및 유효하지 않은 키로 인해 서비스가 중단될 위험.
   - **조치**: 최신 Groq 모델(`llama-3.3-70b-versatile`) 지정 및 실존 검증 데이터셋 기반 RAG 파이프라인 구축. 외부 API 장애 시에도 무중단으로 동작하는 '로컬 지능형 복구 엔진' 도입.
3. **결함 3**: 기존 가짜 점박이 지도와 임의 가상 장소 생성으로 인한 환각 문제.
   - **조치**: 5대 자치구(노원, 도봉, 강북, 중랑, 성북)의 실존 좌표/전화번호/특징을 갖춘 정밀 데이터베이스를 구축하고, 카카오맵 SDK 동적 로더 및 고해상도 인터랙티브 벡터 맵 폴백을 구현함.
4. **결함 4**: 모바일 환경에서 추천이 발생하면 사용자 의사와 무관하게 지도 화면으로 강제 이동되던 문제.
   - **조치**: 강제 전환을 제거하고, 직관적인 하단 3단 내비게이션 바(`대화`, `장소`, `지도`)를 제공하여 사용자가 직접 원하는 뷰를 통제하도록 개선함.
