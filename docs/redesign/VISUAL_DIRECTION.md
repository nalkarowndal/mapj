## 3. 사진 및 비주얼 금지 원칙

1. **음식 사진 스타일**: 자연광, 실제 음식 색감, 따뜻한 원목·도기 배경, 과도한 채도/필터 금지, 4:3 비율 고정으로 CLS 0 유지.
2. **출처·진실성 준수**:
   - AI 생성 이미지는 **홈 Hero 배너, 5개 자치구 에디토리얼 대표 이미지, 10대 테마 큐레이션 대표 이미지**에만 한정 사용하며 `ASSET_MANIFEST.md`와 UI에 명시.
   - 실제 매장 사진이 확보되지 않은 음식점에는 절대 스톡/AI 음식 사진을 매칭하지 않고 전용 플레이스홀더(`/images/placeholder-table.svg`)를 표시.
3. **금지 시각 요소**: 메인 고정 사이드바, 다크 네이비·골드, 글래스모피즘/네온/다중 그라데이션, 무의미한 이모지, 모든 요소를 카드 박스로 감싸는 과밀 레이아웃, 일반 사용자 화면 내 개발자/API 설정 UI.
